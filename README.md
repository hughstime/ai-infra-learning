# AI 算力产业链学习

这是一个面向手机阅读的静态课程网页，主题是 **AI 算力产业链与数据中心**。

内容形式：

- 图：产业链结构图、训练与推理对照
- 文：课程讲义、概念卡片、检查表
- 声：网页内置中文朗读，支持章节切换和语速调节

已上线课程：

- 第 1 课：AI 算力基础
- 第 2 课：AI 芯片分工图解
- 第 3 课：HBM 与先进封装
- 第 4 课：AI 数据中心入门

## 本地预览

```bash
python3 -m http.server 4173
```

然后打开：

```text
http://localhost:4173
```
